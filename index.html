Como pensa um computador?

Turing de Bolso

Comece pelo aquecimento, monte três máquinas escolhendo as linhas do código e depois escreva as suas no simulador. Tudo na notação de quádruplas.

1. Escreva sua máquina

Cada linha é uma instrução, a quádrupla:

q3estado atual
1símbolo lido (0 ou 1)
Doperação
q4próximo estado

Lê-se: “no estado q3, lendo 1, mova uma casa para a direita e vá para q4”.

  • Operações: 1 escreve um traço, 0 apaga, D move para a direita, E move para a esquerda. Cada instrução faz uma única ação.
  • Entrada: o número n é escrito com n + 1 traços (0 é 1, 2 é 111), e os argumentos são separados por um único 0.
  • Início: a máquina começa no estado q1, sobre o traço mais à esquerda.
  • Parada: a máquina para quando não existe instrução para o par (estado, símbolo lido). Não pode haver duas instruções para o mesmo par.
  • Saída: a saída m é escrita com m traços (a fita em branco representa 0). A máquina deve parar no seu estado de maior número, com o cabeçote sobre o primeiro traço.
  • Escreva uma quádrupla por linha. Comentários começam com #.
